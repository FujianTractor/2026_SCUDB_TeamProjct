# 课程设计报告素材

## 1 绪论

### 1.1 引言

高校教务管理是高校信息化建设的重要组成部分。系统通过数据库集中管理教学资源、学生选课、成绩录入和统计查询，提高教务管理效率。

### 1.2 国内外研究现状

国内外高校普遍采用信息化教务系统支撑课程计划、选课、课表和成绩管理。成熟系统强调数据一致性、权限控制、流程规范和统计分析能力。

### 1.3 本文主要工作

本文完成 SCU EduAdmin 高校教务管理系统的需求分析、数据库设计、后端接口设计、前端页面实现和测试用例设计。

### 1.4 系统开发的核心技术简介

系统采用 Vue 3、Element Plus、Spring Boot、MyBatis Plus 和 MySQL 8.x，实现前后端分离的 B/S 架构。

## 2 系统分析建模

### 2.1 系统需求概述

系统面向管理员、教师和学生。管理员维护基础数据，教师管理授课班级和成绩，学生完成选课、退课、课表和成绩查询。

### 2.2 系统数据存储需求

系统需要保存用户权限、学院专业班级、学生教师、课程教学班、教室课表、选课记录、成绩和操作日志。

### 2.3 系统功能性需求

系统需要支持登录、RBAC 菜单、基础数据 CRUD、选课事务、成绩录入、报表统计和多表查询。

## 3 系统设计建模

### 3.1 系统架构

系统采用前后端分离架构。前端通过 Axios 调用 RESTful API，后端通过 MyBatis Plus 访问 MySQL。

### 3.2 系统数据库设计

数据库设计包含 18 张核心表，使用主键、外键、唯一约束、非空约束和检查约束保证完整性。

### 3.3 系统功能设计

后端按 Controller、Service、Mapper、Entity 分层。Controller 接收请求，Service 实现业务逻辑与事务，Mapper 完成数据库访问。

## 4 系统实现

### 4.1 实现环境与工具

Java 17、Spring Boot 3、MySQL 8、Node.js、Vue 3、Vite、Element Plus。

### 4.2 创建数据库及导入初始数据

依次执行 `schema.sql` 和 `data.sql`，创建数据库结构、视图、约束和演示数据。

### 4.3 主要程序模块实现

登录模块使用 BCrypt 校验密码。选课模块使用事务完成容量、重复选课和时间冲突检查。成绩模块支持批量插入或更新。

## 5 系统测试

### 5.1 测试环境

后端本地端口 8080，前端本地端口 5173，数据库为 MySQL 8.x。

### 5.2 测试设计

测试覆盖基础 CRUD、多表查询、完整性约束、选课事务、成绩录入和登录权限。

## 6 工作总结和心得体会

### 6.1 工作总结

本项目完整覆盖数据库课程设计要求，体现了关系建模、完整性约束、复杂查询、视图、事务和系统实现。

### 6.2 心得体会

通过本项目可以更清晰地理解数据库设计与业务系统实现之间的关系，尤其是外键约束和事务对数据一致性的保障作用。
